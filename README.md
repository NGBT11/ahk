HotKeys v1.0

CapsLock как модификатор для Windows: рабочие столы, раскладка окон, исправление раскладки текста, поиск выделенного, прозрачность окна и игровой режим. Живёт в трее.

Как запустить

Скачай HotKeys.exe ниже и запусти. AutoHotkey ставить не нужно.

Что умеет
CapsLock + 1 / 2: рабочие столы
CapsLock + A / D / S / W: окна по половинкам, по центру, развернуть
CapsLock + Space: исправить раскладку выделенного (ghbdtn → привет)
CapsLock + G / Y / X: Google / Яндекс / перевод выделенного
CapsLock + колесо: прозрачность окна
CapsLock + H: шпаргалка по всем хоткеям
Ctrl + Alt + G: игровой режим (блокирует Win и отключает комбинации)

Полный список клавиш в README.

Важно
Шаблоны текста (CapsLock + 3 / 4 / 5) в .exe стоят по умолчанию заглушками. Чтобы поставить свои, поменяй их в windows.ahk и скомпилируй заново.
SmartScreen или антивирус могут ругаться на неподписанный .exe. Это обычная история для скриптов AutoHotkey, исходник открыт.
Нужна Windows 10 или 11.
