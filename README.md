# HotKeys

Небольшой скрипт AutoHotkey для Windows: клавиша `CapsLock` становится модификатором для горячих клавиш, а курсором можно управлять с клавиатуры или геймпада.

**Последний релиз — [HotKeys v1.1](../../releases/tag/v1.1).** Готовый `HotKeys.exe` можно скачать на странице релиза; устанавливать AutoHotkey для запуска не нужно. [Все релизы](../../releases).

Требуется Windows 10 или 11.

## Возможности

- Переключение рабочих столов, управление окнами и их прозрачностью.
- Исправление текста, набранного не в той раскладке (`ghbdtn` → `привет`), поиск и перевод выделенного текста.
- Вставка текстовых шаблонов и быстрый запуск программ.
- Управление курсором, кликами и прокруткой с клавиатуры или совместимого с XInput геймпада.
- Игровой режим: блокирует клавишу Win и отключает комбинации скрипта.
- Шпаргалка с горячими клавишами и меню в системном трее.

## Установка

### Готовый файл

Скачай `HotKeys.exe` из [последнего релиза](../../releases/latest) и запусти. AutoHotkey устанавливать не нужно.

### Из исходника

Установи [AutoHotkey v1.1](https://www.autohotkey.com/) — версия v2 не подходит — и открой `windows.ahk`.

При обновлении сначала закрой старую копию скрипта через меню в трее (**Exit**), иначе одновременно будут работать две копии.

## Горячие клавиши

Основные комбинации работают при зажатом `CapsLock`.

### Окна и рабочие столы

| Клавиши | Действие |
|---|---|
| `1` / `2` | Переключить рабочий стол влево / вправо |
| `A` / `D` | Перемес��ить окно в левую / правую половину экрана |
| `S` | Разместить окно по центру |
| `W` | Развернуть / восстановить окно |
| `T` | Переключить режим «поверх всех окон» |
| `Q` | Закрыть окно |
| Колесо мыши | Изменить прозрачность активного окна |
| Средняя кнопка мыши | Сбросить прозрачность |

### Текст

| Клавиши | Действие |
|---|---|
| `Space` | Исправить раскладку выделенного текста (EN ↔ RU) |
| `G` / `Y` | Искать выделенное в Google / Яндексе |
| `X` | Перевести выделенное через Google Переводчик |
| `3` / `4` / `5` | Вставить один из трёх текстовых шаблонов |

### Звук и программы

| Клавиши | Действие |
|---|---|
| `↑` / `↓` | Увеличить / уменьшить громкость |
| `M` | Выключить / включить звук |
| `E` / `N` / `C` | Открыть Проводник / Блокнот / Калькулятор |
| `B` | Открыть браузер |
| `R` | Открыть Windows Terminal или, если он не установлен, cmd |

### Курсор с клавиатуры

Удерживай `CapsLock` и используй клавиши:

| Клавиши | Действие |
|---|---|
| `I` / `J` / `K` / `L` | Двигать курсор вверх / влево / вниз / вправо |
| `U` | Левая кнопка мыши; удержание — перетаскивание |
| `O` | Правая кнопка мыши |
| `,` / `.` | Прокрутка вверх / вниз |

Чем дольше удерживается клавиша движения, тем быстрее перемещается курсор. Одновременное нажатие клавиш позволяет двигаться по диагонали.

### Геймпад как мышь

Режим выключен по умолчанию. Включи его сочетанием `Ctrl + Alt + M` или пунктом **Gamepad as mouse** в меню трея. Поддерживаются Xbox 360, Xbox One, Xbox Series и совместимые геймпады через XInput.

| Кнопка | Действие |
|---|---|
| Левый стик | Двигать курсор; удерживай `LB` для точного режима |
| Правый стик | Прокрутка |
| `A` или `RT` | Левая кнопка мыши; удержание — перетаскивание |
| `B` или `LT` | Правая кнопка мыши |
| `X` | Enter |
| `Y` | Открыть экранную клавиатуру |
| `Back` | Esc |
| `Start` | Клавиша Win |
| Крестовина | Стрелки с автоповтором |
| `LB` + `RB` + нажатие обоих стиков | Выключить режим управления мышью |

### Прочее

| Клавиши | Действие |
|---|---|
| `H` | Показать / скрыть шпаргалку |
| `Shift + CapsLock` | Использовать обычный CapsLock |
| `Ctrl + Alt + G` | Включить / выключить игровой режим |
| `Win + F12` | Включить режим управления панелью задач; затем `F12` скрывает или показывает её |

## Игровой режим и ограничения

Игровой режим включается через `Ctrl + Alt + G` или меню трея. В нём блокируются обе клавиши Win и отключаются комбинации с `CapsLock`; управление курсором с клавиатуры и геймпада также отключено.

Не включай режим геймпада как мыши во время игры: кнопки геймпада, в частности `A`, будут выполнять клики мышью. В окнах, запущенных от имени администратора, скрипт тоже нужно запускать от имени администратора.

SmartScreen или антивирус могут предупреждать о неподписанном `.exe`. Исходный код открыт. В готовом `.exe` текстовые шаблоны являются заглушками: для своих значений измени их в исходнике и собери файл заново.

## Свои шаблоны и сборка

В исходнике настрой три значения `Snip1`, `Snip2` и `Snip3`, затем перезапусти скрипт. Чтобы собрать `.exe`, открой контекстное меню `windows.ahk` и выбери **Compile Script**. Для корректного отображения кириллицы выбери в Ahk2Exe Base File **Unicode 64-bit** и сохрани исходник в UTF-8 с BOM.
