# Hotkeys

Скрипт горячих клавиш для Windows на AutoHotkey v1.1. Клавиша `CapsLock` используется как модификатор: с её помощью можно управлять окнами, рабочими столами, звуком, текстом и курсором. Дополнительно поддерживается управление мышью с XInput-геймпада.

Требуется Windows 10 или 11 и AutoHotkey v1.1 для запуска исходника. AutoHotkey v2 не подходит.

## Возможности

- Управление виртуальными рабочими столами.
- Перемещение, разворачивание, закрытие окон и режим «поверх всех окон».
- Изменение и сброс прозрачности активного окна.
- Управление громкостью.
- Исправление текста, набранного в неправильной раскладке (EN ↔ RU).
- Поиск выделенного текста в Google и Яндексе, перевод через Google Переводчик.
- Вставка трёх настраиваемых текстовых шаблонов.
- Запуск Проводника, Блокнота, Калькулятора, браузера и терминала.
- Управление курсором, кликами и прокруткой с клавиатуры.
- Управление курсором и мышиными кнопками с совместимого XInput-геймпада.
- Игровой режим и управление видимостью панели задач.
- Шпаргалка горячих клавиш и меню в системном трее.

## Установка и запуск

1. Установи AutoHotkey **v1.1**.
2. Сохрани исходник в кодировке **UTF-8 с BOM**.
3. Запусти `Hotkeys.ahk`.

Если скрипт уже запущен, перед запуском второй копии закрой первую через пункт **Exit** в меню системного трея.

## Горячие клавиши

Основные комбинации ниже выполняются при удержании `CapsLock`, если не указано иное.

### Окна и рабочие столы

| Комбинация | Действие |
|---|---|
| `CapsLock + 1` | Переключить на предыдущий виртуальный рабочий стол |
| `CapsLock + 2` | Переключить на следующий виртуальный рабочий стол |
| `CapsLock + A` | Переместить окно в левую половину экрана |
| `CapsLock + D` | Переместить окно в правую половину экрана |
| `CapsLock + S` | Разместить окно по центру |
| `CapsLock + W` | Развернуть окно или восстановить прежний размер |
| `CapsLock + T` | Переключить режим «поверх всех окон» |
| `CapsLock + Q` | Закрыть активное окно |

Переключение рабочих столов можно включать и выключать через меню трея.

### Прозрачность

| Комбинация | Действие |
|---|---|
| `CapsLock + Колесо вверх` | Сделать активное окно менее прозрачным |
| `CapsLock + Колесо вниз` | Сделать активное окно более прозрачным |
| `CapsLock + Средняя кнопка мыши` | Сбросить прозрачность активного окна |

### Звук

| Комбинация | Действие |
|---|---|
| `CapsLock + ↑` | Увеличить громкость |
| `CapsLock + ↓` | Уменьшить громкость |
| `CapsLock + M` | Включить или выключить звук |

### Запуск программ

| Комбинация | Действие |
|---|---|
| `CapsLock + E` | Открыть Проводник |
| `CapsLock + N` | Открыть Блокнот |
| `CapsLock + C` | Открыть Калькулятор |
| `CapsLock + B` | Открыть Google в браузере по умолчанию |
| `CapsLock + R` | Запустить Windows Terminal; если запуск не удался — командную строку |

### Текст и поиск

| Комбинация | Действие |
|---|---|
| `CapsLock + 3` | Вставить шаблон `Snip1` |
| `CapsLock + 4` | Вставить шаблон `Snip2` |
| `CapsLock + 5` | Вставить шаблон `Snip3` |
| `CapsLock + Space` | Исправить раскладку выделенного текста EN ↔ RU |
| `CapsLock + G` | Найти выделенный текст в Google |
| `CapsLock + Y` | Найти выделенный текст в Яндексе |
| `CapsLock + X` | Перевести выделенный текст через Google Переводчик |

Шаблоны `Snip1`, `Snip2` и `Snip3` настраиваются в начале исходного файла.

### Курсор и мышь с клавиатуры

| Комбинация | Действие |
|---|---|
| `CapsLock + I` | Двигать курсор вверх |
| `CapsLock + J` | Двигать курсор влево |
| `CapsLock + K` | Двигать курсор вниз |
| `CapsLock + L` | Двигать курсор вправо |
| `CapsLock + U` | Левая кнопка мыши |
| `CapsLock + O` | Правая кнопка мыши |
| `CapsLock + P` | Средняя кнопка мыши (нажатие колёсика) |
| `CapsLock + ,` | Прокрутка вверх |
| `CapsLock + .` | Прокрутка вниз |

Удержание `U`, `O` или `P` удерживает соответствующую кнопку мыши — можно перетаскивать объекты. Движение курсора ускоряется при длительном удержании клавиш; одновременное нажатие направлений позволяет двигаться по диагонали.

### Геймпад как мышь

Режим включается сочетанием `Ctrl + Alt + M` или через меню трея (**Gamepad as mouse**). Поддерживаются геймпады, совместимые с XInput.

| Кнопка геймпада | Действие |
|---|---|
| Левый стик | Движение курсора |
| Правый стик (вертикаль) | Прокрутка |
| `A` или `RT` | Левая кнопка мыши; удержание — перетаскивание |
| `B` или `LT` | Правая кнопка мыши; удержание — перетаскивание |
| Нажатие `R3` | Средняя кнопка мыши |
| `X` | Enter |
| `Y` | Открыть экранную клавиатуру Windows |
| `Back` | Esc |
| `Start` | Клавиша Win |
| Крестовина | Стрелки вверх, вниз, влево и вправо с автоповтором |
| `RB` | Открыть переключатель окон Alt+Tab; при открытом переключателе — следующее окно |
| `LB` | Команда «Назад» в браузере/Проводнике; при открытом Alt+Tab — предыдущее окно |
| `A` при открытом Alt+Tab | Подтвердить выбор окна |
| `B` при открытом Alt+Tab | Отменить переключение |
| `L3 + R3` (удерживать около 1 секунды) | Выключить режим управления мышью с геймпада |

После последнего действия в Alt+Tab переключатель автоматически подтверждает выбор примерно через 2 секунды бездействия.

### Системные сочетания

| Комбинация | Действие |
|---|---|
| `Shift + CapsLock` | Переключить обычный CapsLock |
| `Ctrl + Alt + G` | Включить или выключить игровой режим |
| `Ctrl + Alt + M` | Включить или выключить режим геймпада |
| `Win + F12` | Включить или выключить возможность управления панелью задач клавишей F12 |
| `F12` | Скрыть или показать панель задач, если управление включено |
| `CapsLock + H` | Показать или скрыть шпаргалку |

## Игровой режим

Игровой режим включается через `Ctrl + Alt + G` или меню трея. В этом режиме блокируются клавиши Win и отключаются комбинации с `CapsLock`. Управление курсором с клавиатуры и геймпада также не выполняется.

## Меню системного трея

Через меню трея доступны переключатели:

- управление панелью задач клавишей F12;
- переключение виртуальных рабочих столов;
- игровой режим;
- управление мышью с геймпада;
- шпаргалка горячих клавиш;
- запуск скрипта вместе с Windows.

Пункт **Exit** завершает работу скрипта.

## Сборка EXE

Для компиляции исходника в `.exe` используй **Ahk2Exe**, входящий в экосистему AutoHotkey v1.1:

1. Открой `Hotkeys.ahk` в Ahk2Exe.
2. Выбери Unicode 64-bit Base File.
3. Укажи имя выходного файла, например `Hotkeys.exe`.
4. Выполни компиляцию.

Перед распространением проверь работу собранного файла на Windows. SmartScreen или антивирус могут предупреждать о неподписанном исполняемом файле.
