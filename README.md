# HotKeys
 
Небольшой скрипт на AutoHotkey с удобными горячими клавишами для Windows. Клавиша **CapsLock** превращается в модификатор: все команды вызываются как `CapsLock + клавиша`. Живёт в трее, ничего не устанавливает и не лезет в систему.
 
## Возможности
 
- Переключение рабочих столов, раскладка окон по половинкам экрана, окно поверх всех
- Исправление текста, набранного не в той раскладке (`ghbdtn` → `привет`)
- Поиск и перевод выделенного текста в один клик
- Прозрачность активного окна колесом мыши
- Вставка текстовых шаблонов (почта, имя, телефон)
- Быстрый запуск программ
- Игровой режим: блокирует клавишу Win и отключает все комбинации
- Шпаргалка по хоткеям прямо на экране
## Установка
 
**Готовый .exe (проще всего).** Скачай `HotKeys.exe` со страницы [Releases](../../releases) и запусти. AutoHotkey ставить не нужно. Иконка появится в трее.
 
**Из исходника.** Установи [AutoHotkey **v1.1**](https://www.autohotkey.com/) (не v2, синтаксис другой), скачай `windows.ahk` и дважды кликни по нему.
 
Автозапуск включается в меню трея: **Run at Windows startup**. Ярлык создаётся на текущее расположение файла, поэтому сначала положи программу в постоянную папку.
 
## Горячие клавиши
 
Все комбинации ниже работают вместе с зажатым `CapsLock`. Буквенные хоткеи привязаны к физическим клавишам, поэтому работают и в русской, и в английской раскладке.
 
### Окна и рабочие столы
 
| Клавиши | Действие |
|---|---|
| `1` / `2` | рабочий стол влево / вправо |
| `A` / `D` | окно в левую / правую половину экрана |
| `S` | окно по центру |
| `W` | развернуть / вернуть окно |
| `T` | окно поверх всех |
| `Q` | закрыть окно |
| `Колесо мыши` | прозрачность окна (вверх плотнее, вниз прозрачнее) |
| `Средняя кнопка` | сбросить прозрачность |
 
Раскладка окон учитывает несколько мониторов: окно прилипает к тому экрану, на котором находится.
 
### Текст
 
| Клавиши | Действие |
|---|---|
| `Space` | исправить раскладку выделенного текста (EN ↔ RU, направление определяется само) |
| `G` | искать выделенное в Google |
| `Y` | искать выделенное в Яндексе |
| `X` | перевести выделенное (Google Переводчик, на русский) |
| `3` / `4` / `5` | вставить шаблон 1 / 2 / 3 |
 
### Звук и программы
 
| Клавиши | Действие |
|---|---|
| `↑` / `↓` | громкость + / − |
| `M` | mute |
| `E` | проводник |
| `N` | блокнот |
| `C` | калькулятор |
| `B` | браузер |
| `R` | терминал (Windows Terminal, а если его нет, то cmd) |
 
### Прочее
 
| Клавиши | Действие |
|---|---|
| `H` | показать / скрыть шпаргалку (исчезает сама через 12 секунд) |
| `Shift + CapsLock` | обычный CapsLock |
| `Ctrl + Alt + G` | игровой режим вкл / выкл |
| `Win + F12` | включить режим скрытия панели задач, после этого `F12` прячет и показывает её |
 
## Игровой режим
 
Включается через `Ctrl + Alt + G` или пункт в меню трея. Пока он активен:
 
- обе клавиши **Win** заблокированы, чтобы случайно не вылететь из игры на рабочий стол;
- все `CapsLock`-комбинации отключены.
Выключается тем же `Ctrl + Alt + G`.
 
## Меню в трее
 
Правый клик по иконке: переключатели панели задач, рабочих столов и игрового режима, шпаргалка, автозапуск, выход. Двойной клик по иконке переключает рабочие столы.
 
## Свои шаблоны
 
В начале файла `windows.ahk` есть три переменные:
 
```autohotkey
global Snip1 := "your.email@example.com"
global Snip2 := "Иван Иванов"
global Snip3 := "+7 900 000-00-00"
```
 
Замени значения на свои и перезапусти скрипт. Если пользуешься готовым `.exe`, шаблоны придётся поменять в исходнике и скомпилировать заново (см. ниже).
 
## Сборка .exe
 
1. Открой папку со скриптом, правый клик по `windows.ahk`, затем **Compile Script**. Либо Пуск, затем AutoHotkey, затем **Convert .ahk to .exe**.
2. В Ahk2Exe выбери Base File **Unicode 64-bit** (иначе русские буквы могут сломаться).
3. Файл должен быть сохранён как **UTF-8 с BOM**.
## Известные особенности
 
- Исправление раскладки не трогает точку и запятую в русском тексте, чтобы не ломать обычные предложения. Такие знаки при необходимости поправь вручную.
- После исправления раскладка клавиатуры сама не переключается.
- Антивирус или SmartScreen могут ругнуться на неподписанный `.exe`. Это типично для скомпилированных скриптов AutoHotkey: исходник открыт, можно проверить и собрать самому.
- Шаблоны и копирование выделенного идут через буфер обмена. Прежнее содержимое буфера возвращается обратно, но на очень больших данных (например, картинках) это может занять время.
- Макросов и автокликеров нет, поэтому с античитами проблем быть не должно. Но на всякий случай в онлайн-играх включай игровой режим или выходи из скрипта.
